# Google Earth Engine code – Spatiotemporal Transferability in GeoAI

Google Earth Engine (JavaScript API) code used in the study:

**Spatiotemporal Transferability in GeoAI: Quantifying Machine Learning Domain Shift Using Cohen's d and Spearman's Correlation in a Mountainous Landscape**

## Files
- `GEE_2025.js` – analysis for 2025
- `GEE_2024.js` – analysis for 2024

All analyses were implemented in Google Earth Engine (JavaScript API). Python (Google Colab) was used only for figure preparation. Reference samples are available from the corresponding author upon reasonable request.
